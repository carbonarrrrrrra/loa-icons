# LoA Icons

Unofficial JP Princess Connect! Re:Dive WebP icon library.

https://carbonarrrrrrra.github.io/loa-icons/

The hourly GitHub Actions workflow checks Expugn/priconne-diff for the JP version and names, validates the official asset manifest and bundle MD5, extracts new icons using UnityPy, and deploys GitHub Pages. Existing image files remain available. Failed extraction stops publication. Source schema changes require maintenance. GitHub schedules can be delayed and inactive repository schedules may be disabled after 60 days; check Actions if updates stop.

Images belong to Cygames and their respective owners. This is an unofficial fan utility.
